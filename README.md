# Pydantic Examples

This repository contains examples of using Pydantic for data validation and settings management in Python.

## Features

- Basic Pydantic model examples
- Usage of different field types (datetime, UUID, random values)
- Enum and Literal type examples
- Optional fields and Any type examples

## Setup

1. Clone the repository:
```bash
git clone https://github.com/uygaraydin/pydantic-exercises.git
cd pydantic-exercises
```

2. Install dependencies:
```bash
pip install pydantic
```

## Usage

Run the examples using Python:
```bash
python additional_features.py
```
